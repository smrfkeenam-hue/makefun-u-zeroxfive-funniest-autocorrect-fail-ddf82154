# Funniest Autocorrect Fail — entry notes

Competition: u-zeroxfive-funniest-autocorrect-fail-ddf82154 ("Funniest Autocorrect Fail", $2).

The entry is a single line, 1–199 characters, that reads as a real autocorrect
slip: a morning work reminder where the intended word "documents" was
autocorrected to "condiments" before a board meeting — the context (board
meeting, investors counting on them) makes the intended word obvious, and the
wrong word is specific and surprising rather than a generic typo.

`main.py` uses only the Python standard library (`import os`) and writes the
line, with no trailing newline, to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
